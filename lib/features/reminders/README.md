# المتابعات والتذكيرات

## المنفذ
- إنشاء مهام مستقلة أو مرتبطة بعميل مع تاريخ ووقت وأولوية وملاحظة.
- حالات جديدة ومجدولة ومكتملة ومؤجلة وملغاة.
- عرض النشطة والمكتملة والمؤجلة وإبراز المتأخرة.
- إتمام متابعة مرتبطة بعميل يسجل حدثاً في سجل التواصل.
- صلاحيات داخل المستودع وسجل تدقيق للإنشاء وتغيير الحالة.
- تخزين SQLite محلي دون إنترنت.

## المرحلة التالية
الإشعارات المحلية المجدولة وإعادة جدولتها بعد إعادة تشغيل الجهاز، ثم تعيين المهام للمستخدمين وإدارة تقويم المتابعات.
