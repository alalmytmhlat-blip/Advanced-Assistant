# محرك الاستيراد متعدد الصيغ

يدعم PDF النصي وDOCX وXLSX وPPTX وCSV وTSV وTXT وJSON وJSONL وXML وHTML وMarkdown. ملفات Office الحديثة تقرأ محليًا من OOXML. CSV/TSV يحافظ على الخلايا المقتبسة ويحوّل الصفوف إلى معاينة جدوليّة. لا يُحفظ شيء قبل المعاينة والاختيار.

PDF المصور والصور وملفات Office القديمة DOC/XLS/PPT والملفات المشفرة ليست مدعومة بعد وتحتاج محركات إضافية.
