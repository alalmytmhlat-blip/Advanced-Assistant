# العملاء

طبقة بيانات العملاء تستخدم SQLite محليًا وتفرض الصلاحيات من AuthorizationService في كل عملية:
- البحث والقائمة تحترم نطاق العملاء المعين للمستخدم.
- القراءة الفردية تتطلب customer.read ونطاقًا صالحًا.
- الإنشاء يتطلب customer.create.
- التعديل يتطلب customer.update.
- الأرشفة تتطلب customer.archive.
- الرصيد الحالي لا يدخل في نموذج التعديل ولا يتغير عند تعديل بيانات العميل؛ له مسار مستقل بصلاحية balance.update.
