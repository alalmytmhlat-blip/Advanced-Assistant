# استيراد PDF

## مساران منفصلان
1. العملاء: الاسم والهاتف والعنوان والرصيد الحالي إن وجد وملاحظات/تصنيف.
2. الأصناف: الاسم الأصلي والرمز والمقاس والوحدة والكمية والفئة.
لا يخلط التطبيق ملف العملاء بملف الأصناف.

## التدفق
اختيار الملف، التحقق من النوع والحجم، استخراج النص والجداول، اكتشاف الحقول، معاينة وربط الحقول، كشف التكرارات والتعارضات، اختيار سياسة التكرار، تأكيد، transaction، تقرير النتائج.

## السلامة
الحفاظ على الاسم والرمز والمقاس الأصلي؛ لا تصحيح يغير الحقل؛ لا قلب إشارة الرصيد؛ القيم غير الواضحة للمراجعة ولا تُخمن؛ لا استبدال دون موافقة؛ لا الاحتفاظ بالملف إلا باختيار المستخدم.

OCR للملفات المصورة ليس افتراضًا في V1. يضاف بعد اختيار محرك يدعم العربية واختبار دقته، مع وسم النص بأنه OCR ومراجعة بشرية.

اختبر PDF عربي وأرقام هندية/عربية/لاتينية وصفحات متعددة وجداول مكسورة وفارغ ومحمي وكبير ومكرر.
