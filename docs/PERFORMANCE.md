# الأداء والاستجابة

لا ينتظر المستخدم نموذجًا سحابيًا لفتح شاشة أو البحث أو الحفظ أو عرض البيانات الأساسية.

## أهداف قبول أولية (تُقاس ولا تعتبر نتائج محققة)
- تشغيل بارد إلى أول إطار تفاعلي: أقل من 2 ثانية.
- فتح سجل عميل محلي: أقل من 500ms.
- بحث محلي شائع: أقل من 300ms.
- حفظ محلي بسيط: أقل من 300ms.
- لا تجميد أثناء PDF أو التقارير.

## قواعد التنفيذ
Indexes للحقول المستخدمة؛ pagination؛ debounce؛ isolate/compute للمهام الثقيلة؛ لا disk/network داخل build؛ تحميل الملفات عند الحاجة؛ caching محدود مع invalidation؛ معاملات DB قصيرة؛ تجنب N+1؛ قياس frame times والذاكرة وحجم APK؛ تجنب المؤثرات الثقيلة.

## أداء الذكاء
intent محلي أولًا؛ النتائج المحلية فورية؛ streaming عند دعم المزود؛ timeouts وحدود tokens؛ إلغاء الطلب عند مغادرة السياق؛ cache آمن بعمر محدد؛ fallback عند انقطاع الإنترنت. لا يعتمد إصدار يسبب فقد بيانات أو يتجاوز الأهداف دون قرار موثق.
