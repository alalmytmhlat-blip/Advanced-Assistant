# فهرس وثائق المساعد الذكي PRO

المرجع الرسمي للمشروع. الأولوية لسجل القرارات ثم متطلبات المنتج ثم المعمارية.

- PRODUCT_REQUIREMENTS.md: الرؤية والنطاق والوظائف والقيود.
- ARCHITECTURE.md: الطبقات وبنية Flutter.
- AI_ENGINE.md: الذكاء الهجين والأدوات وسلامة التنفيذ.
- DATA_MODEL.md: الجداول وقواعد البيانات.
- SECURITY.md: الخصوصية والصلاحيات.
- PERFORMANCE.md: السرعة ومعايير القياس.
- UX_SPEC.md: الواجهة وتجربة الاستخدام.
- PDF_IMPORT.md: الاستيراد والتحقق.
- ROADMAP.md: مراحل التنفيذ.
- TESTING.md: الاختبارات ومعايير القبول.
- OPERATIONS.md: التشغيل والنسخ والاستعادة.
- RELEASE_CHECKLIST.md: فحص إصدار APK.
- DECISIONS.md: سجل القرارات.
- DEFINITION_OF_DONE.md: تعريف اكتمال الميزة.

قواعد المحافظة على المعرفة: لا تحذف متطلبًا معتمدًا دون قرار موثق؛ كل ميزة جديدة تدخل المتطلبات والخطة والاختبارات؛ كل تغيير DB يحتاج migration؛ لا تعتبر الشاشة وحدها ميزة مكتملة؛ لا تضع أسرارًا أو بيانات حقيقية في Git.
