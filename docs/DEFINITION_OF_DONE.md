# تعريف اكتمال الميزة

لا تعتبر الميزة مكتملة حتى تتحقق البنود المنطبقة:
- [ ] المتطلبات والسلوك موثقان.
- [ ] العربية وRTL مدعومان.
- [ ] حالات التحميل والفراغ والخطأ واضحة.
- [ ] منطق الأعمال منفصل عن الواجهة.
- [ ] التحقق من المدخلات والصلاحيات في طبقة الأعمال.
- [ ] لا بيانات تجريبية في الإنتاج.
- [ ] العمليات الحساسة تسجل في audit.
- [ ] الفشل لا يسبب فقدًا أو تغييرًا جزئيًا.
- [ ] اختبارات الوحدة والبيانات والواجهة ناجحة.
- [ ] اختبارات Android الفعلية للميزات الحساسة ناجحة.
- [ ] الأداء مقاس ولا مهام ثقيلة على UI thread.
- [ ] الوثائق والخطة وCHANGELOG محدثة.
- [ ] لا أسرار أو بيانات شخصية في Git.
- [ ] تعليمات الاستخدام والاستعادة والصيانة متاحة.

وجود زر أو شاشة غير موصولة لا يعني اكتمال الوظيفة.
