# متطلبات المنتج — المساعد الذكي PRO

## الرؤية
تطبيق Android عربي سريع لإدارة العملاء والأرصدة والمخزون والمتابعات، مع مساعد ذكي يتعامل مع البيانات الفعلية. Local-first: الوظائف الأساسية لا تتوقف عند انقطاع الإنترنت.

## المستخدمون والأدوار
- المدير: إدارة كاملة والمستخدمون والإعدادات والنسخ والاستعادة واعتماد العمليات الحساسة.
- الموظف: الوظائف والبيانات التي يمنحها المدير.
- مدير المخزون: الأصناف والكميات والتنبيهات واستيراد الأصناف.
- محصل الديون: الاطلاع المصرح على العملاء والأرصدة وتسجيل المتابعة، دون نظام دفعات.
تُفرض الصلاحيات في منطق الأعمال لا بمجرد إخفاء الأزرار.

## الأنظمة
### لوحة التحكم
ملخص العملاء والمخزون، مهام اليوم، المتابعات المتأخرة والقادمة، تنبيهات انخفاض الكمية، مؤشرات الأرصدة، وروابط مباشرة للسجلات مع احترام الصلاحيات.

### العملاء
إنشاء وتعديل وأرشفة وفق الصلاحيات؛ الاسم والهاتف والعنوان والتصنيف والملاحظات؛ بحث بالاسم والهاتف مع مراعاة اختلافات الكتابة العربية؛ ملف موحد يضم سجل التواصل والمتابعات والرصيد الحالي؛ كشف التشابه دون دمج تلقائي.

### الأرصدة
رصيد حالي signed: الموجب والسالب والصفر قيم مختلفة. لا قلب إشارة ولا تصفير تلقائي. تعديل الرصيد يتطلب صلاحية وسببًا ويسجل السابق والجديد والفاعل والتوقيت. لا دفعات ولا سندات ولا فواتير ولا دفتر أستاذ ولا قيود محاسبية.

### المخزون
الأصناف: الاسم الأصلي والرمز والوحدة والمقاس/الوصف والكمية وحد التنبيه والملاحظات. الحفاظ حرفيًا على الاسم والمقاس والرمز. بحث وتصفية. تعديل الكمية بصلاحية وسجل تدقيق. التنبيه لا يغير الكمية تلقائيًا.

### المتابعات والتذكيرات
مهام مرتبطة بعميل أو مستقلة، موعد وتوقيت وأولوية وحالة وملاحظة ومالك. الحالات: جديدة، مجدولة، تمت، مؤجلة، ملغاة. إشعارات Android محلية يعاد جدولتها بعد إعادة التشغيل. سجل التواصل يحتفظ بالمكتمل.

### المساعد الذكي
محادثة عربية؛ فهم أسئلة العملاء والأرصدة والمخزون والمتابعات والتقارير؛ بحث وتلخيص وتحليل واقتراح؛ أوامر typed مع معاينة وتأكيد؛ احترام الدور؛ مصدر لكل معلومة تشغيلية؛ لا اختلاق بيانات. محلي للمهام الفورية وسحابي للغة والتحليل المتقدم عند التوفر والموافقة.

### التقارير
تقارير العملاء والمتابعات والمخزون والأرصدة الحالية، فلاتر وتصدير PDF/CSV، وقت الإنشاء ومصدر البيانات. لا تقارير مبيعات أو مشتريات أو أرباح أو كشوف محاسبية.

### المستخدمون
إدارة حسابات وأدوار وصلاحيات وسجل تدقيق؛ لا تظهر بيانات غير مصرح بها في البحث أو الملخصات أو المساعد.

### استيراد PDF
مسار مستقل للعملاء ومسار للأصناف؛ استخراج نص ومعاينة وربط حقول وكشف تكرارات قبل الحفظ؛ تقرير مستورد/مكرر/مرفوض/مراجعة؛ لا استبدال تلقائي. OCR للملفات المصورة مرحلة مستقلة بعد الاختبار.

### النسخ الاحتياطي
نسخة متسقة، checksum وإصدار schema، تأكيد ونسخة أمان قبل الاستعادة.

## متطلبات غير وظيفية
العربية RTL وخط Cairo، واجهة لا تتجمد، عمل محلي دون إنترنت، أمان وصلاحيات وتدقيق، صيانة واختبارات وترحيل.

## خارج النطاق
لا مبيعات أو مشتريات أو فواتير أو ضرائب أو مدفوعات أو سندات أو قيود أو دفتر أستاذ. لا مزامنة متعددة الأجهزة في V1 دون قرار مستقل. لا إرسال WhatsApp/SMS آلي دون تكامل وموافقة منفصلين.
