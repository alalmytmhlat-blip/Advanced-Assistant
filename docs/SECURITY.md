# الأمان والخصوصية والصلاحيات

- أقل صلاحية لازمة وdeny-by-default؛ التحقق في Domain/Use Case وليس الواجهة فقط.
- لا مفاتيح API أو كلمات مرور أو tokens في APK أو Git؛ لا بيانات عملاء أو PDF أو أسرار في logs.
- المدير إدارة كاملة؛ الموظف حسب منح المدير؛ مدير المخزون للأصناف والكميات؛ محصل الديون للاطلاع المصرح وتسجيل المتابعة فقط، بلا دفعات أو قيود.
- كلمات المرور عبر KDF موثوق (Argon2id أو scrypt أو PBKDF2 حسب دعم المنصة)، لا نص صريح ولا hash سريع. حماية مفاتيح التشفير المحلية عبر Android Keystore ومكتبة موثوقة.
- استخدم document picker بدل صلاحيات تخزين عامة، وتحقق من نوع الملف وحجمه ومحتواه.
- مفاتيح مزود AI على الخادم فقط؛ TLS ومصادقة وحدود استخدام ومهلة وحجم طلب؛ تقليل البيانات الشخصية؛ خيار تعطيل السحابة؛ لا ترسل DB كاملة.
- استجابات النموذج structured وتتحقق قبل التنفيذ. الأدوات allowlist ولا SQL مباشر.
- القراءة المصرح بها مباشرة؛ التعديل يعرض قبل/بعد؛ الحذف والاستيراد الجماعي والاستعادة تتطلب تأكيدًا. أعد التحقق من الصلاحية قبل التنفيذ.
- audit للأحداث الحساسة: الدخول وتغيير الدور وتعديل الرصيد/الكمية والاستيراد والحذف والاستعادة وأوامر AI، دون أسرار.
- النسخ تتطلب checksum وفحص schema ونسخة أمان قبل الاستبدال، وتشفيرًا عند اعتماد الآلية.
- راجع dependencies والأسرار وصلاحيات Android ومدخلات PDF وprompt injection قبل الإصدار.
