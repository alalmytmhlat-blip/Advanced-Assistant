# AI Gateway Backend

خدمة وسيطة آمنة بين Android ومزود الذكاء الاصطناعي. مسؤولياتها المصادقة، إدارة مفاتيح المزود في environment/secret manager، حدود الاستخدام والمهلة وحجم الطلب، تقليل البيانات الشخصية، allowlist للأدوات، structured output، وسجلات بلا أسرار.

ممنوع وضع API keys في Flutter أو Git؛ وممنوع اتصال النموذج بSQLite مباشرة أو تنفيذ SQL/Dart/shell من النموذج. لم يعتمد إطار الخادم أو مزود AI بعد؛ يحسم بقرار مستقل بعد تقييم التكلفة والتوافر والخصوصية.
