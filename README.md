# المساعد الذكي PRO — Advanced Assistant

> نظام Android عربي لإدارة العملاء والأرصدة والمخزون والمتابعات، مع مساعد ذكاء اصطناعي هجين ومحرك محلي سريع.

## الحالة
المستودع مخصص لإعادة بناء التطبيق من الصفر. هذه المرحلة تؤسس وثائق المنتج، القرارات المعمارية، هيكل Flutter، معايير الجودة وخطة التنفيذ. لا تعتبر أي ميزة مكتملة حتى تُنفذ وتُختبر وتُوثق.

## القرارات المعتمدة
- إعادة بناء مستقلة من الصفر داخل هذا المستودع.
- Flutter لتطبيق Android أصلي، بواجهة عربية RTL وخط Cairo.
- Local-first: SQLite هو مصدر البيانات المحلي الأساسي، وتعمل الوظائف الأساسية دون إنترنت.
- ذكاء هجين: محرك محلي سريع + بوابة آمنة لنماذج الذكاء الاصطناعي السحابية.
- جميع أقسام التطبيق السابق: العملاء، الأرصدة، المخزون، المتابعات، التقارير، المستخدمون والصلاحيات، استيراد PDF، النسخ الاحتياطي.
- الأولوية للسرعة والاستقرار وصحة البيانات قبل الزخرفة البصرية.

## نطاق المنتج
### الأنظمة
1. لوحة تحكم ومؤشرات وتنبيهات.
2. العملاء وملفاتهم وسجل التواصل والملاحظات.
3. الأرصدة الحالية الموجبة والسالبة، مع سجل تغييرات موثق عند تعديلها.
4. الأصناف والمخزون والكميات والوحدات وحدود التنبيه.
5. المهام والمتابعات والمواعيد والإشعارات المحلية.
6. مساعد ذكي يفهم العربية ويبحث ويحلل ويقترح وينفذ إجراءات مصرحًا بها.
7. تقارير وإحصائيات قابلة للتصدير.
8. المستخدمون والأدوار: مدير، موظف، مدير مخزون، محصل ديون.
9. استيراد ملفات PDF للعملاء والأصناف كلٌ على حدة مع معاينة قبل الحفظ.
10. نسخ احتياطي واستعادة مع التحقق من سلامة الملف.

### قيود لا يجوز تجاوزها
- التطبيق ليس برنامج محاسبة.
- لا مبيعات، لا مشتريات، لا فواتير، لا دفعات، ولا قيود محاسبية.
- الرصيد قيمة حالية مستقلة؛ يجب الحفاظ على إشارته الموجبة أو السالبة وعدم قلبها أو تصفيرها تلقائيًا.
- لا حذف أو تعديل جماعي للبيانات دون معاينة وتأكيد وصلاحية.
- لا تغيير تلقائي لأسماء الأصناف أو المقاسات أو الرموز.
- لا اختلاق بيانات في إجابات الذكاء الاصطناعي؛ كل معلومة تشغيلية يجب أن ترتبط بنتيجة من قاعدة البيانات.
- لا مفاتيح API أو أسرار داخل تطبيق Android أو المستودع.

## بنية المستودع
- `lib/`: تطبيق Flutter والميزات والطبقات المشتركة.
- `docs/`: مواصفات المنتج والهندسة والبيانات والأمان والاختبار والتشغيل.
- `test/`: اختبارات الوحدة والواجهات والتكامل.
- `.github/workflows/`: التحليل والاختبارات وبناء APK.
- `backend/`: عقد بوابة الذكاء الاصطناعي والخادم، دون أسرار أو مفاتيح فعلية.

## مبدأ الإنجاز
كل ميزة تمر بدورة: متطلبات واضحة ← تصميم ← تنفيذ ← اختبار ← توثيق. لا توصف بأنها مكتملة لمجرد وجود شاشة أو زر. راجع [قائمة الإنجاز](docs/DEFINITION_OF_DONE.md).

## بدء التطوير
يتطلب Flutter SDK مستقرًا وAndroid SDK. بعد تجهيز بيئة Flutter:
```bash
flutter pub get
flutter analyze
flutter test
```
يُنشأ مجلد منصة Android بواسطة Flutter عند إعداد المنصة أو عبر سير عمل البناء.

## اللغة والواجهة
- العربية هي اللغة الافتراضية.
- اتجاه RTL في جميع الشاشات والنماذج والجداول.
- خط Cairo.
- تصميم بسيط عالي الوضوح، خفيف على الأجهزة، مع دعم الشاشات الصغيرة.
- اللون البنفسجي يميز المساعد الذكي، مع هوية أزرق/أبيض للتطبيق.
